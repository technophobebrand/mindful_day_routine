# Mindful Dag - Plum Village Android App

Deze repository bevat de broncode voor de **Mindful Dag** Android applicatie, ontworpen om rust, aandacht en momenten van stilte in te bouwen in een drukke werk- en gezinsweek.

## Functies
- **Schema's:** Werkdag (Gezin), Weekend en Plum Village Traditioneel.
- **Aanpasbaar & Backup:** Volledig aanpasbare tijdblokken met JSON Backup en Restore.
- **Klankschaal Synthesizer:** Live Web Audio API klankschalen (Traditioneel, Tempelbel, Tingsha, Gong).
- **Achtergrond & Notificaties:** Achtergrond-ondersteuning met automatische ademhalingsherinneringen en push-notificaties.
- **Subtiele Versioning & License:** Open Source (MIT) en subtiel weergegeven versienummer.
